# HijabHouse 👗

HijabHouse is a web application for a modest fashion store. The website allows users to browse dresses, view product details, create an account, log in, add products to a shopping cart, and place orders.

## Features

- Home page
- Dress collection
- Product details
- User registration and login
- Shopping cart
- Checkout
- Order management
- Admin section

## Technologies

- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: ASP.NET Core MVC / C#
- Database: SQL Server
- ORM: Entity Framework Core
- Version Control: Git & GitHub

## About

HijabHouse was created as a web application project to practice and demonstrate the development of an e-commerce website using ASP.NET Core MVC and SQL Server.
